# CG2 評価課題3 ReadMe

## <加点要素>

・ Stanford Bunnyの描画  それぞれ独立させてSRT,Lightingができるようにした。

・ Utah Teapotの描画  Bunnyと同じようにSRT,Lightingができ、uvChecker に変更できるようになっている。

・ Lighting方式の変更  Lightingなし,Lambert,Half Lambertが球や、Bunny,teaで独立して動的に切り替えれるようにした。

・ Lambertian Reflectance  方向、色、輝度を変更できる。

・ Half Lambert  方向、色、輝度を変更できる。

・ UVTransform  spriteの中身を変更できる。

・ 球の描画  SRTの変更が可能。

・ 複数のモデルの描画  sphere,teapot,Bunnyのモデルを出し、SRTが独立してできる。

・ Sound  Soundクラスを作り、実行されたときにSEを鳴らす。
