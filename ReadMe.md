## CG3 評価課題1

## 起動操作
シーンにフォーカスして **B キー**を押すか、ImGui の **「中央にブラックホールを出す (B)」** を押します。
デモ画面にフォーカスして **M キー**を押すか、ImGui の **「CosmicMistを再生 (M)」** を押します。


## ブラックホール Editor
CG3 のデモに、ブラックホール演出を編集する ImGui の画面を組み込んでいます。吸い込む粒の数、爆発までの時間、主衝撃波の色を調整できます。

## ブラックホール演出のこだわり
 **星が光の尾を引いて吸い込まれる。** 粒ごとに出発位置や到着時刻をずらし、中心までの距離を縮めながら角度を進めています。五芒星には進行方向に沿った光の尾を付け、中心に近づくと徐々に消えるようにしています。
 **黒い中心と回転する光の輪。** 中心は背景を覆うように暗く描き、その周囲には青紫の光を重ねています。吸い込んだ粒の割合に応じて黒い中心が広がり、周囲の光も強くなります。
 **爆発を閃光・衝撃波・破片で見せる。** 中心が光ったあと、3 本の衝撃波が少しずつ時間をずらして広がります。同時に、星形の破片や火花が方向と速度を変えて飛び散り、徐々に消えていきます。
 **形と光をシェーダーで生成する。** 星や光の輪は HLSL で描き、位置や色を変えた多数の板ポリを GPU インスタンシングでまとめて描画しています。

### Editor の使い方

 **吸い込む粒の数** — スライダーで 12～1200 個に調整します。
 **爆発までの時間** — スライダーで 0.5～12 秒に調整します。
 **主衝撃波の色** — 色見本をクリックして、爆発時に広がる主衝撃波の色を選びます。
 **編集中の設定でプレビュー** — 保存前の値を使って、その場で演出を再生します。
 **設定を保存** — 実行時の作業フォルダに `blackhole.txt` を書き出します。
 **保存済みの設定を読み込み** — ファイルから読み込んだ値を編集欄に表示します。

### 保存した演出をデモで再生する
編集画面とプレビュー・通常再生の呼び分けは [main.cpp](main.cpp) にあります。設定の保存・読み込みと、設定値に沿った演出の制御は [BlackHoleEffect.cpp](BlackHoleEffect.cpp) にあります。

## CosmicMist
Effekseer 付属の CosmicMist サンプル（Pierre 作）をベースに、Editor で色を調整した演出です。
派手な色から始めることでどんどん透けるように見せるところが拘りポイントです。

### 出し方
再生には Effekseer の DirectX 12 SDK が必要です。別の PC では、Visual Studio の開発者用 PowerShell でリポジトリのルートから次を実行してからビルドします。`-SdkSource` には EffekseerForCpp 1.80.8 の `CMakeLists.txt` があるフォルダを指定します。

```powershell
.\SetupEffekseer.ps1 -SdkSource 'C:\path\to\EffekseerForCpp1.80.8'
```

### 演出と組み込みのポイント
 **Editor で調整した色をデモに反映。** 編集済みの `CosmicMist.efkefc` を FKEngine が起動時に読み込みます。色を調整し直す場合は Effekseer で同じファイルに保存し、デモを起動し直します。[エフェクトデータ](Resources/Effekseer/CosmicMist/CosmicMist.efkefc)
 **自作エンジンのシーン内で再生。** Effekseer の描画に FKEngine のカメラ行列を渡し、背景のゆがみには、そのフレームのシーンをコピーしたテクスチャを使います。[描画処理](EffekseerSceneEffect.cpp)
